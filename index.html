Optical QR Transfer

인터넷/블루투스로 파일을 보내는 게 아니라,
화면 QR ↔ 카메라로 파일을 넘기는 연습용 PoC.

보내기 (Send) 파일 고르면 QR이 빠르게 바뀜. 노트북 화면이 편함. 받기 (Receive) 카메라로 저 QR을 비추면 조립. 폰이 편함.
  1. npm install → npm run dev
  2. 노트북: Send 페이지에서 파일 선택 (작은 파일 추천, 예: 50~200KB)
  3. 폰: 터미널에 나온 Network 주소로 Receive 접속 (HTTPS 경고 허용)
  4. 카메라 시작 후 노트북 화면을 비춤

참고: decimen-optical-transfer 아이디어를 단순화한 학습용 버전.
전송 구간은 빛만 씀. 페이지를 처음 받을 때는 네트워크가 필요할 수 있음.
